## Принятые решения по дизайну

- Свой стиль, sfon не копируем. Названия разделов как в sfon: Статистика, Продажа, Склад, Долги, Баланс, Расходы.
- Цвет акцента — настройка фирмы. По умолчанию синий, графит — вариант.
- Шрифт Onest (есть казахские буквы и ₸), IMEI — JetBrains Mono.
- Tailwind **3.4**, потому что ноутбук на Windows 7 (Chrome 109). Tailwind 4 в Chrome 109 ломается — проверено.
- Режим «старый ноутбук» вместо отдельной старой версии.
- Сейчас одна фирма (Prime Mobile) и один магазин; у каждого будущего владельца своя фирма, свои сотрудники и роли.

## Как пересобрать (для разработчика)

Папка `src/`:

```bash
./fetch_photos.sh          # временные фото моделей (в репозиторий не кладём)
python3 erp.py             # HTML экранов для компьютера
python3 mobile.py          # HTML экранов для iPhone
node render.js             # PNG в ../screens (нужен Playwright)
node render.js /путь/к/chrome109/chrome   # те же экраны в Chrome 109
```

Режимы страницы задаются классом на `<html>`: `dark`, `accent`, `legacy`. HTML-файлы не хранятся в репозитории — они собираются заново.

## Баннеры — `screens/bannery/`

Trade-in, новинка iPhone 17 Pro Max, б/у с гарантией. Каждый в двух форматах: широкий 1672×941 (сайт на компьютере) и квадрат 1080×1080 (телефон, Instagram).
Стиль «постер»: крупный текст, синий круг, телефоны на подиуме. Телефоны — настоящие фото, текст — живой (меняется и переводится на казахский без перерисовки). Генерации нет.

**Временное:** фото телефонов с GSMArena (видна мелкая подпись в углу), цены и условия акций условные, адрес магазина придуман. Для сайта нужны официальные фото или свои, условия Trade-in и рассрочки — от Кайрата.

Пересборка: `src/vitrina/vitrina.py`, `src/bannery/bannery.py` (рядом `render.js`). Нужны вырезанные фото телефонов в папке `img/` — их скрипт `src/fetch_photos.sh` пока не готовит, это ручной шаг.
