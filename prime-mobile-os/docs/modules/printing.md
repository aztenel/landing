# Модуль «Печать» Ф1–Ф12 (ТЗ 06 §6–§9) — раунд 5

Способ 1 из ТЗ: HTML точного размера → окно печати Chrome. Шаблоны — `resources/views/print/*`, стиль — `resources/css/print.css`
(шрифт Onest с казахскими буквами и ₸, только чёрный). Помощники — `app/Domain/Printing/Printing.php`: kk + ru по
настройке «Печать → язык», деньги, маска телефона, Code 128 / EAN-13 / QR в SVG, «ДУБЛИКАТ / КӨШІРМЕ», запись в журнал.

| Форма | Адрес (имя маршрута) | Размер |
|---|---|---|
| Ф1 Чек продажи | `erp.print.sale` (старый `erp.pos.receipt` ведёт сюда) | лента 80 / 58 (`?w=58`) / A4 (`?w=a4`) |
| Ф2 Чек возврата | `erp.print.return` | лента |
| Ф3 Гарантийный талон | `erp.print.warranty` | A5 / A4 / лента 80 (`?f=`) |
| Ф4 Накладная: приход, перемещение, возврат поставщику | `erp.print.invoice` | A4; цены — только с правом на себестоимость |
| Ф5 Акт trade-in | `erp.tradein.print` (раунд 3) | A4 |
| Ф6 Ценник 70×50, лист A4 по 8 | `erp.print.price_tags?units=…` | без казахского названия не печатается |
| Ф7 Термоэтикетка телефона 58×40 | `erp.print.labels?units=…` или `?doc=<приход>` | штрихкод IMEI, QR на сайт |
| Ф8 Этикетка аксессуара 40×30 / 30×20 | `erp.print.accessory_labels?acc=&qty=` или `?doc=` | EAN-13 заводской или внутренний «2…» |
| Ф9 Квитанция о приёме на гарантию | `erp.print.warranty_case` | лента 80 / A5, 2 экземпляра |
| Ф10 Итог смены | `erp.print.shift` | лента, без прибыли |
| Ф11 Квитанция о долге | `erp.print.debt` | A5 |
| Ф12 Акт сверки | `erp.print.reconciliation?type=customer|supplier&id=` | A4 |
| Тестовая печать | `erp.print.test?s=label58x40` | рамка, линейка, штрихкод, QR |

**Электронный чек и гарантия:** QR на чеке ведёт на `<домен сайта>/r/<22 случайных символа>` — без входа, без IMEI
полностью и без телефона (таблица `receipt_links`).

Кнопки: карточка чека (Чек, Гарантия, Расписка о долге), касса после продажи, возврат (Чек возврата), паспорт
(Этикетка, Ценник), склад — выбранные (Этикетки, Ценники), приходы (накладная, этикетки), перемещения (накладная),
гарантия (квитанция), долги (Акт сверки), отчёт О17 (Итог смены).

## Проверено
`tests/Feature/Printing`: каждая форма, дубликат при второй печати, запрет для бухгалтера, ссылка на электронный чек без
входа и без полного IMEI, ценник без казахского — не печатается, контрольная цифра EAN-13 по примеру ТЗ. Вид в Chrome 109 —
`docs/screens/printing/`.

## Что не сделано
- Тихая печать QZ Tray и «принтер магазина» с iPhone (способы 2 и 3) — этап 3 по ТЗ.
- Настоящая проверка на Xprinter: масштаб, размер бумаги в драйвере — только на месте (не проверено).
- Автопечать после продажи (галочка магазина) и «Перепечатать ценники после смены цены» — нет.
- Перевод казахских надписей на формах — черновой, нужен носитель языка.
