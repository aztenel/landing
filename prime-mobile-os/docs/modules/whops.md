## Документы (`StockOpDraft` + `StockOpHandler`, один класс на все виды)

| Документ | Что делает | Право |
|---|---|---|
| Перемещение: отправка ПРМ | в наличии → «В пути» этого документа | `transfer.send` |
| Перемещение: приём ПРМ | принятое → в магазин-получатель, отказ → обратно; отправка становится «принято» | `transfer.accept` |
| Списание СПС | → списан, по себестоимости, с причиной | `stock.write_off`, лимит L15 |
| Возврат поставщику ВЗП | → возвращён поставщику; деньги на счёт или наш долг поставщику уменьшается | `stock.return_supplier` |
| Ревизия РЕВ | недостача → списан; найденный после списания → вернулся со старой себестоимостью; аксессуары ± | сканирует `revision.scan`, проводит `revision.post` |
| Исправление карточки ИЗХ | модель / IMEI / серийный «было → стало», без движения товара; сторно возвращает как было | `stock.unit_edit` (у проданного — только опечатка IMEI) |
| Корректировка себестоимости КСБ | ± к себестоимости телефона на складе | `stock.cost_adjust` (владелец) |

Статусы меняются только по таблице переходов (ядро проверяет каждое движение). После каждого документа и его сторно ночная сверка чистая (тесты).

**Гарантийное обращение ГРО** — не учётный документ: телефон остаётся «продан», у обращения свои статусы: принят → в ремонте у нас / в сервисе → готов → выдан (или отказ).
