# Модуль «Чеки, возвраты, заказы» (salesdocs) — Э4, Э5, Э7

| Экран | Адрес | Класс |
|---|---|---|
| Чеки (Э4) | `/sales` | `App\Filament\Sales\Pages\Sales` |
| Возврат и обмен (Э5) | `/returns`, `/returns?sale={id}` | `App\Filament\Sales\Pages\Returns` |
| Заказы (Э7) | `/orders` | `App\Filament\Sales\Pages\Orders` |

## Правила

- **Кто какие чеки видит:** продавец — свои за 7 дней; админ — чеки своих магазинов; владелец и бухгалтер — все (`Sales::visible()`). Чужой id чека не открывается (404). Прибыль — только с `stock.view_cost`.
- **Возврат:** мастер в 4 шага. Суммы считает сервер (`ReturnCalculator`): доли скидки, бонусы вернуть / аннулировать, удержание за потраченные бонусы, сначала уменьшается долг. Телефон «Целый, в продажу» — только с отметкой «iCloud / FRP отвязан». Продавец (право «только заявкой») — «Отправить заявку», экран ждёт ответа владельца и проводит возврат сам. Админ — в пределах лимитов L7–L9, сверх — та же заявка.
- **Обмен** (`App\Domain\Sales\Services\Exchange`, решение аудита №34): возврат и новая продажа — одной операцией, возврат первым. Возврат отдаёт «Зачёт обмена» (`refundToExchange`), новая продажа берёт его оплатой `exchange_offset`; после пары технический счёт «Зачёт обмена» = 0. Новый товар дороже — клиент доплачивает выбранным способом; дешевле — разница возвращается по обычному правилу.
- **Заказ:** телефон в наличии (скан) или вариант «под заказ», предоплата, продление на 3 дня, отмена = сторно (предоплата возвращается). «Продать» открывает кассу с заказом (`CartService::loadOrder`), F10 на кассе открывает возврат.

## Не сделано

- Акт возврата (печать) — модуль печати.
- Возврат по продажам из sfon (ВДП) — модуль переноса.
- Отдельный список «Возвраты» с фильтрами — пока последние 10 на первом шаге мастера.
