## Документы

- **Акт trade-in ТРД** (`TradeInDraft`, `TradeInHandler`): телефон приходит «на подготовке» с себестоимостью = сумма выкупа; наш же проданный телефон возвращается тем же экземпляром (история продолжается). Часть «в зачёт» идёт через технический счёт «Зачёт trade-in» в чек той же операции (оплата `tradein` со ссылкой на акт, ровно на сумму зачёта); остальное выплачивается из кассы ₸ и/или переводом Kaspi.
- Запреты: iCloud / «Локатор» включён; госбаза «Не верифицирован» / «Заблокирован»; IMEI не сверен с *#06#.
- Лимиты: сетка (L13) — на всю сумму, нет сетки — только владелец, остальным заявка; наличная выплата (L12).
- Сторно: акт с зачётом — только вместе с чеком (`Reverser::reverseMany([продажа, акт])`).
- **Затраты на подготовку ЗПД** (`PrepCostDraft`, `PrepCostHandler`): + к себестоимости телефона на складе; оплачено со счёта или в долг мастеру (поставщику) со сроком.
- **«Готов к продаже»** на экране Э12 — только с ценой продажи и свежей отметкой госбазы «Верифицирован».

## Не сделано

- Фото в акте (добавляются в паспорте; модуль сайта).
- Подсказка «за 90 дней выкупали / продавали» — модуль отчётов.
- Печатный бланк Ф5 — модуль печати заменит вид `tradein.print`.
