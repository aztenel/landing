## Как работает

- Шапка один раз (поставщик, валюта и курс, накладная, оплата: в долг / сразу / частично, срок долга); последние значения запоминаются.
- **Партия** = модель + состояние + закуп + розница → скан IMEI подряд (USB-сканер или камера iPhone). Каждый скан проверяется на сервере: контрольная цифра (Луна), дубль в приходе («Уже отсканирован в этой партии (строка 3)»), IMEI уже есть в базе (код и статус телефона). Плохие строки остаются красными с причиной и не проводятся; проводить можно, только удалив их.
- Счётчик «7 из 10», предупреждения: «отсканировано меньше, чем ожидали», «розница ниже себестоимости».
- Проведение — `PurchaseDraft->post()` с ключом идемпотентности страницы: повторное нажатие не создаёт второй приход. После — ссылки на паспорта новых телефонов (для фото).
- Импорт Excel: шаблон → загрузка → предпросмотр с ошибками по строкам (неизвестная модель, IMEI с ошибкой, дубль, IMEI в базе, цена) → строки становятся партиями; при ошибках «Добавить» не проходит. Лимит 5 000 строк.
- Сторно прихода — из списка, с причиной, правом `doc.reverse`; если телефон уже продан, ядро скажет, что сначала сторнировать продажу.

## Решение по продавцу (сценарий 7)

Продавец без права `stock.cost_edit` **оприходует телефоны без цены закупа**: поле закупа не показывается, а цена из браузера игнорируется. Телефон получает «себестоимость неизвестна» и не продаётся, пока админ не внесёт её документом «Ввод себестоимости» (ВСБ). Аксессуары без цены закупа ядро не принимает, поэтому приход аксессуаров делает админ или владелец.
