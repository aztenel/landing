# Тестовый сервер за одну команду

Для проверки системы и показа клиенту. **Демо-данные** (фирма «Prime Mobile», ~43 телефона, продажи, долги, фото-заглушки).
Настоящий сервер магазина ставится по [README.md](README.md) — без демо-данных.

## Что нужно
- VPS: **Ubuntu 24.04**, от **2 ядер / 4 ГБ / 60 ГБ**. Домен не нужен.
- Доступ к консоли сервера от root (в панели хостинга или по SSH).

## Установка (15–25 минут)
В консоли сервера:
```bash
curl -fsSL https://raw.githubusercontent.com/aztenel/landing/claude/nifty-johnson-nwlyrg/prime-mobile-os/deploy/scripts/demo-install.sh -o demo-install.sh
bash demo-install.sh
```
В конце скрипт покажет адреса ERP и магазина (вида `erp.1-2-3-4.sslip.io` — бесплатное имя по IP сервера) и пароль
демо-входов. Пароль создаётся на сервере и лежит в `/root/prime-demo.txt` — **в чат и в git не пересылать**.

Демо-входы (телефон / пароль из `/root/prime-demo.txt`):
- 77010000001 — Кайрат, владелец (при первом входе — настроить код из Google Authenticator, сохранить запасные коды);
- 77010000002 — Айгерим, продавец;
- 77010000003 — Данияр, продавец.

## Обновить до последней версии
Снова `bash demo-install.sh`. Данные и пароли остаются, при ошибке проверки возвращается прошлая версия.

## Если что-то не так
- «Репозиторий закрытый»: скрипт покажет открытый ключ сервера — добавить в GitHub → Settings → Deploy keys (без права записи)
  и запустить ещё раз.
- «HTTPS не получился»: работает по http. Для проверки хватит; камера и «установить на экран» на iPhone без https не работают.
- Журналы: `/var/www/prime/shared/storage/logs/`, фоновые задачи: `supervisorctl status`.

## Чем отличается от настоящего сервера
- Копии базы лежат **на этом же сервере** (`/var/backups/prime-restic`) — для теста. На настоящем — у второго провайдера.
- Меньше процессов PHP (под 4 ГБ). SSH и firewall не трогает.
- Сервер теста удалите после показа: данные демо, настоящие данные магазина сюда не заносить.
