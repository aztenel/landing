## Концепция: «THE ART OF THE CUT» — по логотипу клиента
Типовая система взята из логотипа: Oswald (капс, как надпись по кольцу) для заголовков, меню и кнопок; Rye (W и слово WINCHESTER) для «Winchester», «5.0» и римских цифр; Manrope для текста. Палитра сдвинута к бордово-чёрному фону логотипа, кремовые секции остаются. Квадратики-разделители из кольца логотипа используются в лейблах. Rye не содержит кириллицы, поэтому им набраны только латинские слова.
Выбрана из трёх:
1. **Heritage Editorial** (выбрана) — крупный serif, тёмные и кремовые секции чередуются, бордо для Premium, латунь точечно.
2. **Brick & Light** — фото-first, полноэкранные кадры интерьера; требует большого набора съёмки, которого пока нет.
3. **Barber Manual** — минимализм в духе технического каталога; меньше эмоций для Instagram-аудитории.

## Как заменить фото
Положите файл в `assets/photos/` под нужным именем — рамка-заглушка заменится сама, без правок кода:
`hero.jpg`, `master-toni.jpg`, `master-aidos.jpg`, `master-aidyn.jpg`, `master-alisher.jpg`, `master-ruslan.jpg`, `interior-1.jpg` … `interior-4.jpg`.
Нужно снять/получить у владельца: рабочее место с кирпичной стеной и светом (hero, вертикаль), портреты 5 мастеров, общий план зала, детали (дерево, инструмент), руки мастера в работе, зону ожидания. Для Premium — отдельный кадр процедуры (опционально).
